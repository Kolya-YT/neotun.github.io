Как понимать результаты

Доступна — браузер смог установить соединение с адресом локации.

Недоступна — адрес не ответил браузеру, а источник статусов также не подтверждает доступность.

Заблокирована ТСПУ — источник статусов сообщает о подтверждённой блокировке для российских сетей. Сам по себе тайм-аут браузера блокировку не доказывает.

Перебои / Не удалось проверить — источник сообщает о проблемах либо данных недостаточно для уверенного вывода.

Проверка показывает доступность из текущей сети и не гарантирует работу всех протоколов или приложений. Результат может отличаться у разных операторов.
